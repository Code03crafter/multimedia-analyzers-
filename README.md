# Multimedia Metadata Analyzers

Three standalone Python scripts, each extracting metadata from a
different media type. Built as separate lab tasks:

| Folder | Task | Extracts |
|--------|------|----------|
| `01-image-analyzer/` | Task 1 | Image metadata + EXIF |
| `02-audio-analyzer/` | Task 3 | Audio metadata (via ffprobe) |
| `03-video-analyzer/` | Task 2 / LAB 3 | Video + audio-track metadata (via ffprobe) |

Each folder is fully self-contained — its own script, its own README,
no shared code between them. See each folder's README for setup and
usage instructions.
